

# Sentiment Analysis Dashboard

## Project Description

This project analyzes social media comments, reviews, or tweets and classifies them into positive, negative, and neutral sentiments using Natural Language Processing (NLP). The dashboard helps understand public opinion, customer feedback, and trending topics through graphical visualization.

## Features

* Sentiment Analysis
* Positive, Negative, Neutral Classification
* Social Media Data Analysis
* Trend Analysis
* Data Visualization using Charts and Graphs
* Interactive Dashboard

## Technologies Used

* Python
* Pandas
* NLP (Natural Language Processing)
* TextBlob / NLTK
* Matplotlib
* Power BI
* CSV Dataset

## Project Files

* sentiment_analysis_dataset.csv
* sentiment_analysis.ipynb

## Output

This project generates:

* Sentiment distribution graph
* Positive vs Negative analysis
* Trend visualization
* Word frequency analysis
* Interactive dashboard for sentiment insights
